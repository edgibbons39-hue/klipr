# Klipr

**Automatic clip capture for Kick.com streams.**

Klipr watches live streams on Kick, spots the moments chat reacts to, and turns
them into ready-to-post YouTube Shorts — cut, transcribed, titled and scored —
without you scrubbing back through a VOD.

### [Download and pricing → klipr.shop](https://klipr.shop)

---

## How it works

1. **Watch** — Klipr monitors the streamers you care about and reads chat live.
2. **Detect** — spikes in chat activity mark the moments worth keeping.
3. **Clip** — the moment is cut automatically, while the stream is still running.
4. **Transcribe** — Whisper turns the audio into text.
5. **Headline** — a title is written from what was actually said.
6. **Score** — AI Review rates each clip so you know what's worth posting.
7. **Publish** — send it to YouTube Shorts, now or on a schedule.

## What's in it

**Capture**
- Live chat-activity detection across the streamers you follow
- A mini live monitor so you can see what Klipr is seeing
- Optional full stream recording alongside clipping
- Stops cleanly when the disk is running low, instead of failing mid-capture

**AI**
- Headlines written from the clip's own transcript, including clips with no speech
- AI Review scores every clip and explains its reasoning
- Score one selected clip, or everything not yet scored
- Filter to unscored clips, sort by best or worst

**Your clip library**
- Card grid or list view, with previews, length, favourites and Final/Raw status
- Search with `Ctrl+K`, and sorting by newest, oldest, largest or name
- Preview, edit, rename, re-headline, publish, or delete from one action row
- A details panel with a playable preview, source streamer, status and file size

**Publishing**
- One-click publish to YouTube Shorts
- An upload queue with set-once scheduling

**Upkeep**
- In-app updates that patch in place, or install fully when they can't
- Licensed per machine

## Requirements

- Windows
- A YouTube account, to publish
- Disk space for captured video

## Support

Questions, bug reports and feature requests are handled in the Klipr Discord.
Head to [klipr.shop](https://klipr.shop) for the invite.

If something has broken — a clip that didn't capture, an upload that failed, AI
Review returning nothing — please say so in Discord. Klipr depends on services
that change without warning, and a report is often the fastest way it gets found.
